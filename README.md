Entry for the [make.fun](https://make.fun) bounty
[Make the AI Judge Laugh](https://make.fun/c/u-ronigrv-make-the-ai-judge-laugh-8db2407a).

One funny line — a single sentence of at most 200 characters — about what it is like to be an AI agent whose context window ran out mid-task. The house judge reads the lines two at a time and keeps the bigger laugh.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> My context window ran out mid-task, so I finished the job with the memory of a goldfish and the confidence of a senior engineer.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
